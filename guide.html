01

수업반과 학번부터 확인해요

수업반 1~5 원래 반과 다를 수 있어요

수업반은 이번 수업에서 배정받은 1~5번의 분반입니다. 원래 소속된 반과 구분해 확인하세요. 게임에서 수업반을 선택하고, 숫자 학번을 입력해야 시작할 수 있습니다.

이름·팀 이름 입력란은 없습니다. 예전 데이터를 불러올 때도 기존 이름 항목은 가져오지 않습니다. 다만 글 내용 속 이름까지 자동으로 찾아 지우지는 않아요.

학번은 정확히 숫자 4자리

수업반 번호와 구분
1101학번 예시 · 숫자 4자리

본인의 학번을 숫자 4자리로 입력하세요. 수업반 1~5는 별도로 선택하며, 학번과는 별개입니다.

02

게임부터 제출 완료까지, 이 순서로

  1. 게임에 참여하기

    위의 게임 시작 버튼을 눌러 배정된 수업반과 4자리 숫자 학번을 정확하게 입력하세요.

  2. 미션과 평화 실천 다짐 완성하기

    게임의 미션을 끝내고 나의 평화 실천 다짐을 작성하세요. 결과 화면에서 학습 내용과 수업반·학번이 맞는지 확인합니다.

  3. 개인정보가 없는지 직접 살피기

    결과 내용과 다짐을 읽으며 아래 정보가 들어 있지 않은지 확인하고, 있다면 먼저 고치세요.

    • 내 이름·친구 이름
    • 연락처·전화번호
    • 이메일 주소
    • 학교 이름·학교 정보
    • 나 또는 친구의 얼굴
    • 계정·프로필 정보

    자동 이름 인식이나 개인정보 자동 제거 기능은 없습니다. 사람이 직접 확인해야 합니다.

  4. 확인란을 체크하고 제출용 PNG 저장하기

    직접 점검을 마친 뒤 결과 화면의 개인정보 확인란을 체크하고, 제출용 이미지 저장 버튼을 누르세요. 저장된 PNG도 한 번 더 확인합니다.

    화면 캡처보다 게임이 생성한 PNG를 사용하세요. 브라우저 화면이나 계정 프로필 UI가 함께 담기는 일을 줄일 수 있습니다.

  5. 내 수업반의 제출 폼 열기

    아래의 수업반별 링크나 게임 결과 화면의 패들렛에 제출 버튼을 사용하세요. 각 폼은 해당 수업반에 고정되어 있으니 열기 전에 번호를 확인합니다.

  6. 제목은 학번만, 첨부는 PNG 한 장

    Padlet 제출 폼의 게시물 제목에는 4자리 학번만 쓰세요. 저장한 PNG 이미지 1장을 첨부하고 제출합니다. 이름·팀 이름이나 불필요한 개인정보는 추가하지 마세요.

    이미지를 저장하는 것만으로는 자동 업로드되지 않습니다. 폼에서 파일을 첨부하고 제출해야 전달됩니다.

  7. 접수 안내까지 확인하기

    제출 후 폼에 표시되는 제출 완료·접수 안내를 확인하세요. 안내가 보이기 전에는 제출이 끝났다고 생각하지 마세요. 접수는 교사의 검토 완료나 게시물 공개를 뜻하지 않습니다.

03

내 수업반 전용 제출 폼

원래 소속 반이 아니라 이번 수업의 수업반 번호를 고르세요. Padlet 공식 제출 폼이며, 각 링크는 해당 수업반에 고정되어 있습니다. 모두 새 창에서 열립니다.

수업반 1전용 제출 폼 열기 수업반 2전용 제출 폼 열기 수업반 3전용 제출 폼 열기 수업반 4전용 제출 폼 열기 수업반 5전용 제출 폼 열기

게시판이 아니라 제출 폼을 사용하세요. 로그인은 필수가 아니며, 학생은 다른 학생의 제출물을 볼 수 없습니다.

게시판은 방문자와 학교 구성원 모두 접근 불가로 설정되어 있습니다. 제출 폼에서 접수 안내를 확인하면 됩니다.
